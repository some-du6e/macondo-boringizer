# Macondo Boringizer

Makes Macondo boring by getting rid of anything jolly.

## How to install

### Chrome
1. Get the file ending with chrome
2. Unzip the file
3. Go to `chrome://extensions/` and turn on developer mode
4. Click `Load unpacked` and select the unzipped file
### Firefox
1. Click on the file ending with xpi
0. A popup like this will show up, click continue to installation and continue normally
